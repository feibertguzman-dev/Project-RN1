Sobre el Proyecto

Proyecto de clasificación binaria para diferenciar entre Feibert y Koku usando una Red Neuronal con Transfer Learning exportada desde Google Teachable Machine. Aplicando metodología CRISP-ML.

Objetivo General

Desarrollar, documentar y desplegar un clasificador Feibert vs Koku con énfasis en Redes Neuronales.

Objetivos Específicos

  • Aplicar CRISP-ML
  • Usar Transfer Learning
  • Implementar pipeline eficiente
  • Desplegar con Streamlit
  • Documentar con glosario y tutorial
Aplicación Streamlit Cuaderno Jupyter README

Metodología CRISP-ML

1. Business Understanding

Problema: Clasificar imágenes entre Feibert y Koku. Objetivo: Sistema de inferencia con aplicación web.

2. Data Understanding

Datos recolectados y etiquetados en Teachable Machine: Feibert (0), Koku (1).

3. Data Preparation

Redimensionar, convertir a RGB, normalizar (/255), añadir dimensión batch (1,H,W,3).

4. Modeling

Transfer Learning: modelo base pre-entrenado + cabeza clasificadora. Exportado desde Teachable Machine a Keras (.h5).

5. Evaluation

Validación con imágenes nuevas analizando confianza con función Softmax.

6. Deployment

Aplicación Streamlit con pipeline optimizado usando @st.cache_resource.

Pasos del Proyecto

1. Entrenar en Teachable Machine: Recolectar imágenes Feibert y Koku, etiquetar y entrenar con Transfer Learning.
2. Exportar modelo: Descargar modelo Keras (.h5) y labels.txt.
3. Organizar: Copiar a carpeta models/ manteniendo originales.
4. Analizar en Notebook: Cargar modelo, revisar arquitectura, probar pipeline.
5. Crear App Streamlit: Implementar carga con cache, preprocesamiento e interfaz.
6. Documentar y visualizar: README, glosario, tutorial, index.html.
